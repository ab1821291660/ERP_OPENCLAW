# 图片与图纸解析

## 适用范围

- 图片扩展名：`.png`、`.jpg`、`.jpeg`
- 图纸扩展名：`.dwg`、`.dxf`
- 输入对象来自 MinIO；本技能只负责解析，不负责上传、登录、权限或对象存储。

## 输出要求

1. 文件名、格式、尺寸或文件可读的图纸元数据。
2. 图片：描述可见对象、文字位置、表格、铭牌、标注和可能的缺陷。
3. 图纸：在 DXF 可读时提取图层、实体类型、尺寸标注、文字和图框线索。
4. 区分“文件中直接读取的信息”和“根据可见内容做出的低置信推断”。
5. 给出需要人工复核的区域和补充材料清单。

## 失败与边界

- OCR、图纸尺寸自动测量、三维模型解析和 CAD 专用格式真实转换当前未接通时，必须明确标记为不可用或演示能力。
- 模糊、遮挡、低光照、倾斜图片不得输出确定性识别结果。
- DWG 为专有二进制格式；没有真实 CAD 解析器时，不得声称已读取内部尺寸。
- 不得根据标准型号或经验补全图纸中不存在的参数。
