# 图纸识别（布置图参数提取）

## 数据源声明

当前未接入图纸识别服务（OCR/视觉模型）；本技能定义参数提取清单与核对工作流。用户提供图纸描述或尺寸文字时按清单提取；仅提供图片文件时，说明演示环境暂不支持图片解析，请以文字提供关键尺寸。

## 工作流

1. **提取井道土建参数**：井道净宽 × 净深、井道总高、顶层高度、底坑深度、井道偏差（每 5 层累计偏差）。
2. **提取建筑约束**：机房有无（有机房/无机房）、圈梁位置与间距、牛腿/预留孔、相邻建筑关系（邻梯间距）。
3. **提取设备参数**：拟用梯型、载重、速度、轿厢尺寸、开门型式（中分/旁开/贯通）、层站数。
4. **一致性核对**：将提取参数与 knowledge-search 技能的最小井道规则比对，偏差项列入「待确认项」。
5. **输出**：「布置图参数清单」（表格：参数/数值/来源）→「与设计规则比对结果」→「待确认项」（缺失或冲突的参数）。

## 边界

- 提取的参数必须来自用户描述，不得推断未给出的尺寸。
- 冲突参数（如轿厢宽 > 井道净宽 - 余量）必须显式提示并给修正建议。
