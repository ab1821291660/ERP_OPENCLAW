# 方案评估（多部门会签）

## 适用场景

非标方案完成后，替代技术/研发/采购多部门逐一会签（传统 1–2 周）的智能评审：一次输出各部门评审要点与风险分级。

## 工作流

1. **方案要素核对**：确认方案包含梯型/载重/速度/轿厢/开门型式/对重位置/井道尺寸；缺失项先补齐（联动 knowledge-search 的参数识别清单）。
2. **技术维度评审**（技术部视角）：
   - 井道尺寸余量是否满足最小值（联动 shaft_size_calculator 复核）；
   - 顶层高度/底坑深度与速度等级匹配（缓冲距/越程）；
   - 特殊配置（贯通门/加厚装修/异形井道）的规范符合性。
3. **制造维度评审**（研发/工艺视角）：联动 `process_route` 核对关键工序与改制点，标注非标改制项。
4. **采购维度评审**（采购视角）：联动 erp-purchase 技能核对物料可采购性与交期风险（演示数据源）。
5. **风险分级输出**：
   - 🟢 低风险：参数常规、物料齐套、工序标准；
   - 🟡 中风险：单点非标（如旁开门组合），需技术确认 1 项；
   - 🔴 高风险：多重非标叠加或知识库未命中，建议转技术部门正式会签。
6. **输出结构**：「方案要素」→「分部门评审要点」→「风险分级与结论」→「待确认项」。

## 边界

- 知识库未命中的参数组合必须评为 🔴 高风险并建议人工会签，不得直接放行。
- 评审结论注明"智能评审参考，正式会签以各部门书面确认为准"。
