# ERP 采购查询

## 数据源声明

当前为**演示数据源**：物料主数据存于本技能目录 `references/materials.json`（read_file 读取，建议 limit=1000）。回答中涉及价格/交期/库存时，**必须在末尾声明"以上为演示数据源（未对接客户 ERP），正式报价以采购部 ERP 为准"**。

## 工作流

1. **识别物料**：从用户输入提取物料关键词（梯型 ESW/ESW03 + 部件名：主机/曳引机、控制柜、门机、轿厢、导轨、对重块等）与数量。
2. **读取演示主数据**：调用 `read_file(file_path="<本技能目录>/references/materials.json", limit=1000)`，按物料编码/名称匹配。
3. **匹配与汇总**：
   - 命中：列出物料编码、名称、规格、单价、采购交期（天）、可用库存、数量小计与合计；
   - 未命中：说明演示主数据未覆盖该物料，建议转采购部确认。
4. **成本联动**（可选）：结合 finance-info 技能的成本构成参考，给出订单物料成本估算。

## 输出结构

「物料清单」（表格：编码/名称/规格/单价/交期/库存/数量/小计）→「合计与交期说明」（按最长交期物料说明）→「数据源声明」。

## 边界

- 演示数据仅为样例，不得对外作为正式报价。
- 用户询问的物料不在演示数据中时，如实说明，不编造价格。
