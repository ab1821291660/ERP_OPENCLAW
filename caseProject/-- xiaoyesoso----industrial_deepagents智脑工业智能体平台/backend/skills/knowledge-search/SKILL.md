# 知识库检索（工业大脑）

## 适用场景

用户提出需要设计规范、设备参数、工艺路线或售后规则支撑的问题：非标方案设计、井道尺寸核算、载重/速度选型、开门型式与对重布置、生产工序与会签节点、质保与维保政策等。

## 工作流

1. **识别关键参数**：从用户输入提取梯型/设备族（如 ESW、ESW03）、载重、速度、轿厢尺寸、开门型式、对重位置等；参数不全时先列「待确认项」并追问，不要编造。
2. **调用工具检索条款**：优先调用 `query_design_rules` 工具（关键词可用多个近义词组合，如"井道 尺寸"、"中分门 对重"）；工艺与设备参数问题分别调用 `process_route` / `equipment_params`；售后问题调用 `after_sales_policy`。
3. **确定性计算**：涉及井道尺寸、选型计算时调用 `shaft_size_calculator`，以工具返回为准，不要自行心算。
4. **结构化回答**：按「配置参数」→「计算/选型结果」（引用命中条款）→「待确认项」组织；条款未命中时如实说明并建议转技术部门会签。

## 边界

- 数值结论必须来自工具返回，并提示"以厂家最新设计规范为准"。
- 知识库未覆盖的组合不要编造规范数值。
