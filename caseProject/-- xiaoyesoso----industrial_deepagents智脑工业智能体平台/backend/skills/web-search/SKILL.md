# 联网搜索

## 数据源声明

已接入 **DuckDuckGo 免费检索**（通过 `web_search` 工具，无需 API Key）。检索结果为公开网页摘要（标题、链接、摘要），不含网页全文。

## 标准工作流

1. 把用户问题拆解为 2-4 个具体检索词（含型号/标准号/关键词），例如「GB/T 7588.1-2020 乘客电梯」「ESW03 无机房 布置要求」。
2. 调用 `web_search` 工具执行检索（`query` 为检索词，`max_results` 默认 5，最多 8 条）。必要时换词补检 1-2 次。
3. 筛选权威来源优先引用：标准发布机构（全国标准信息公共服务平台等）、厂家官方文档、行业主管部门公告。
4. 回答时注明来源链接与检索时间；引用关键结论，不整段照抄。

## 失败与降级策略

1. 若 `web_search` 返回 `ERROR:` 开头的文本（网络异常、限流等），明确告知用户联网检索暂不可用。
2. 按 knowledge-search 技能的流程调用本地工具（query_design_rules 等）作答。
3. 提示用户：涉及最新标准/厂家最新规范时，请以官方发布渠道为准。

## 边界

- 只检索摘要，不抓取网页正文；需要原文细节时给出链接让用户自行查阅。
- 搜索结果可能过时或不准确，涉及安全强制的结论必须提示以官方正式发布为准。
