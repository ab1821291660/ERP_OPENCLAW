# 设备日志分析

## 数据源声明

当前为**演示数据源**：示例设备日志存于本技能目录 `references/door-noise-log.txt`（read_file 读取，建议 limit=1000）。分析结论涉及日志数据时，**必须声明"基于演示日志（未对接 IoT 平台），请以现场实际采集日志为准"**。

## 工作流

1. **收集故障现象**：设备型号（ESW/ESW03 等）、故障现象（异响位置、发生频率、伴随报警）、发生时间段。
2. **读取日志**：调用 `read_file(file_path="<本技能目录>/references/door-noise-log.txt", limit=1000)` 获取示例日志时间线；现象与日志特征匹配时按时间线分析。
3. **根因定位**：按"现象 → 报警码 → 时间聚集特征 → 部件定位"链路分析；常见根因（门机滑轨异物/重锤间隙超标/导靴磨损/润滑不足）结合日志特征判定。
4. **规则联动**：调用 `after_sales_policy` 工具查询该机型的售后处置规则（质保内/外、维修响应等级）。
5. **输出处置方案**：「故障现象」→「日志特征与根因」→「处置建议」（现场排查步骤、需更换部件可联动 erp-purchase 查询）→「数据源声明」。

## 边界

- 演示日志仅为样例；现场故障必须以实际采集日志为准。
- 涉及安全回路、制动器等安全部件异常时，优先建议停机检修并转售后工程师。
