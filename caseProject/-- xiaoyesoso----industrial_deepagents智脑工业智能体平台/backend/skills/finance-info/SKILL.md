# 财务信息查询

## 数据源声明

当前为**演示数据源**：成本构成与账期参考存于本技能目录 `references/cost-basis.md`（read_file 读取，建议 limit=1000）。涉及金额、账期、信用的回答**必须声明"基于演示财务参考（未对接财务系统），正式数据以财务部为准"**。

## 工作流

1. **识别诉求**：订单成本估算 / 报价构成 / 账期政策 / 客户信用，四类之一或组合。
2. **读取参考数据**：调用 `read_file(file_path="<本技能目录>/references/cost-basis.md", limit=1000)`。
3. **成本联动**：订单成本估算时先按 erp-purchase 技能取物料清单，再套用成本构成比例（物料 / 制造费用 / 期间费用 / 目标毛利）计算。
4. **输出结构**：「成本构成表」（分项金额与占比）→「报价建议」（含毛利区间）→「账期与信用提示」→「数据源声明」。

## 边界

- 演示比例仅为参考模型，实际按财务部当期标准执行。
- 不对具体客户给出信用评级结论，仅说明查询流程与所需字段。
